These are local design previews rendered from the actual theme section/snippet markup using fixture Shopify data. The demonstration price is $18; the installed theme uses the merchant's real Shopify price and stock. Fonts in this local rendering use the fallback; actual Shopify uses its configured hosted fonts. These previews are not evidence of a connected store, real checkout, email delivery or published deployment.

The bundle now includes a transparent, image-tool-cleaned adaptation of the logo supplied in chat, plus a background-cleaned product mockup. These are presentation assets derived from the supplied images, not additional original photography or pixel-identical exports. The original product mockup remains in the theme. Upload original production-approved artwork/photography through the theme settings to override these assets if needed.

The preview HTML files generated during local validation are not part of the Shopify upload ZIP. The ZIP contains only valid Shopify theme directories.
